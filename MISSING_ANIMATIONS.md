## How to Add Missing Animations

To add these animations to the GLB:

1. **Re-export from Unity:**
   - Open Unity project
   - Select rabbit model with animator controller
   - Ensure all desired animations are linked in the animator
   - Export to GLB with all animations included

2. **Use Blender:**
   - Import `Rabbit.glb`
   - Import external `.anim` files
   - Link animations to the model
   - Re-export as GLB with all animations

3. **Update Flutter Code:**
   - Once animations are in GLB, update `character_view.dart` to use new animation names
   - Consider random selection for variety (like Unity's blend tree)
